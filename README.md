# sociothon-campusbin-smart-waste-routing
**CampusBin** is a smart waste collection system for IIT Roorkee, built for SOCIOTHON 2026. It tracks 30 campus bins from real KML survey data, predicts when they fill, and plans efficient truck routes on the OpenStreetMap road network. A Leaflet dashboard shows live status, forecasts, and the distance, fuel and CO₂ saved.
